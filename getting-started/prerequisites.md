# Prerequisites

What you need before using TPM:

## Essential Requirements

### TPM Access
- **TPM**: Standard version (requires VPS)
- **TPM+**: Premium version (hosted by Coflnet)

### Minecraft & Coflnet
- Minecraft Java Edition account
- [Coflnet account](https://sky.coflnet.com?refId=odeO2g)
- Coflnet Premium or Premium+ subscription

### Config & Coins
- A config (free or paid) - get from [Config Hub Discord](https://discord.gg/QRhjWZjY6s)
- 50-100m+ coins in purse (recommended)
- Discord webhook (optional but recommended)

## Version-Specific

**Standard TPM:**
- VPS (Vultr/Linode recommended)
- 1GB RAM, 1 CPU core minimum
- See [VPS Setup](../advanced/vps-setup.md)

**TPM+:**
- No VPS needed (hosted)
- See [TPM+ Overview](../tpm-plus/overview.md)
