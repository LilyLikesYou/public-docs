# TPM Documentation

**TPM (The Perfect Macro)** - Automated auction house flipper for Hypixel SkyBlock, officially partnered with SkyCofl.

## What is TPM?

An automation tool that connects to SkyCofl to receive flip opportunities and automatically purchases, manages, and relists items for profit.

**Key Features:** Automated flipping, multi-account support, smart relisting, bed spam, Discord notifications, customizable filters, bank management, auto-rotation.

## TPM vs TPM+

- **TPM**: Standard version (requires VPS)
- **TPM+**: Premium version (hosted, advanced features) - [See details](../tpm-plus/overview.md)
